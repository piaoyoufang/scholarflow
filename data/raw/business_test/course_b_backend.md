# Python 后端实战测试资料

## FastAPI 接口分层

FastAPI 项目通常会把接口层、业务层、存储层分开。

接口层负责接收 HTTP 请求、校验参数、返回响应。
业务层负责执行核心逻辑，例如生成学习计划、自动出题、文档入库。
存储层负责读写 SQLite、Chroma 等数据库。

## 异步上传任务

异步上传任务适合处理耗时操作。

用户上传文件后，接口先快速返回 task_id。
后台任务再继续完成文件解析、文本切块、embedding 生成和向量数据库写入。

前端可以通过 GET /tasks/{task_id} 查询任务状态。

常见任务状态包括：

- pending：等待处理
- running：处理中
- success：成功
- failed：失败

## 为什么需要任务表

如果上传大文件时接口一直阻塞，用户体验会很差，也容易超时。

任务表可以记录每个文件的处理进度、错误信息和最终结果，方便前端展示，也方便开发者排查问题。
